# Closed test: 12 testers for 14 days

New personal Play Console accounts must run a **closed test** with at least **12 testers** who stay
opted in for **14 days in a row** before Google allows a production release. Start this as soon as
the Play Console account is verified and the first AAB is uploaded.

## 1. Set up the test in Play Console (once)

1. **Test and release → Testing → Closed testing → Create track** (name it `closed-1`).
2. **Create new release** and upload the same `app-release.aab` used for internal testing.
3. **Testers** tab: choose **Email lists**, create a list named `LangarSeva testers`, and paste the
   Gmail addresses from the tracker below (comma separated). Add a feedback email or URL.
4. **Save → Review release → Start rollout to Closed testing.**
5. Copy the **"Join on the web"** opt-in link from the Testers tab. It replaces `<OPT_IN_LINK>` below.

Each tester must use the **same Gmail** that is signed in to the Play Store on their Android phone.

## 4. After 14 days

1. **Dashboard → Apply for production access.** Google asks a few questions about the test:
   how testers were recruited, what feedback came in and what changed. Answer from the tracker.
2. Review usually takes up to 7 days. After approval: **Production → Create new release →**
   upload the latest AAB → roll out.
